# Dhrumi’s Bengaluru startup opportunities

A public, read-only shortlist of Bengaluru startup and scaleup application pages, last checked **29 September 2026**. Open `index.html` through a web server or visit the GitHub Pages site after publication.

## Research method

- Each counted role has a direct application page that opened during the check. The page records the role, company, work arrangement, employment type, résumé choice, fit explanation, possible gap, and the posting and stage sources. Search results without a working application page were excluded.
- Full-time roles appear first. Internship and trainee programs appear below them. An advertised trainee program is labelled as an internship when full-time conversion is conditional.
- “Strong” indicates direct evidence in Dhrumi’s experience; “possible” means an adjacent move; “stretch” flags a significant skill, degree, domain, or experience gap. The fit explanations are editorial assessments, not employer endorsements.
- A public professional profile is shown only when a current profile can be linked to the named person and company. Otherwise the card points directly to the application page. No personal email or telephone number appears on the site.
- Stage labels come from the linked public job or company page. If that page does not establish a stage, the stage remains unconfirmed. Stage labels describe the company, not the role.
- The source résumés are private and are **not** committed or served. Their experience summaries were used only to write the fit lines.

## Maintenance

`jobs.json` is the only data source. Reopen every `apply` URL before changing `lastVerified`. Remove any closed or moved role from `jobs` until its current application page is found. Review named contact profiles and company stage before updating them. Keep general outreach leads separate from counted roles.

This directory is an independent static site and does not use or expose the Joobler application.
